-------------------------------------------------------------------------------
0. Summary
-------------------------------------------------------------------------------
* Windows 95/98/ME screen readers found: 13 products in about 35 builds
  (outSPOKEN, JAWS, Window-Eyes, Hal95/Hal, Supernova, ProTalk32, Simply
  Talker 98/2000, ASAW, WindowBridge 2.56/2000, Talker95, Wink) plus talking
  tools (Connect Outloud, Home Page Reader, ZoomText/MAGic speech),
  plus 9 DOS readers, 5 Windows 3.1x-only readers, and about 12 XP-era or
  later readers that do not run on 9x.
* Polish: only outSPOKEN for Windows 2.01 (demo) has a Polish user interface
  (language code PLK; Disk1/Plk, Disk2/Plk/Strings; the demo text names Harpo in
  Poznan as distributor). The user's claim is confirmed for outSPOKEN, but the
  only copy is the Windows 95/98 demo inside batol.7z. The ScreenReaders/
  folder has only outSPOKEN tutorial tapes (ManualAndTutorialTapes/Outspoken,
  8 FLAC files).
  The other part of the claim ("all others are English") is not quite right:
  outSPOKEN itself is in 12 languages; Hal 4.50/5.11 are in 5/10 languages;
  Virgo 4.71 is in 7 languages (de/en/fr/it/nl/ro/ru, no Polish); JAWS 3.x and
  later include Eloquence in several languages (English UI only); Blindows is
  German. Hal 5.11 contains Polish screen-language data (CHR00048, Orpheus
  DSO00048, SAMSAPI4 sts00048) but no Polish UI.
* No hardware synthesizer needed (software speech through the sound card):
  JAWS 3.31-6.x (Eloquence bundled), Window-Eyes 3.1 and 5.0 (SAPI 4 and the
  Microsoft engine are on the CD), Hal 4.50/5.11 (Orpheus bundled), outSPOKEN 2.01
  (MSSAPI driver plus a separate SAPI 4 engine), ProTalk32 (Microsoft Voice,
  DECtalk software), Hal95 3.03/Supernova demos (SSILSAPI plus a SAPI engine),
  Window-Eyes 3.0 demo (SAPI), ASAW (MSAPI).
  Hardware only: Window-Eyes 1.x/2.0 demos, Hal95 1.0x demos, Screen Power,
  Windows Master, WindowBridge 1.2/2.21, and all DOS readers.
* Recommended defaults (reasons in section 4):
    Windows 95 / 98 : JAWS for Windows 3.31.35 (jfw33135.exe, 13.9 MB). It has
                      the only installer that can be made fully unattended
                      without recording: plain-text scripts and default.ini.
    Windows ME      : JAWS 4.02.52 (j40252.exe), but it needs a response file.
                      Fallback: JAWS 3.31 (it predates ME; untested there).
    Polish UI       : outSPOKEN 2.01 demo with Languages=PLK and Response.ini.
                      Limit: about 1000 keystrokes per Windows session.
    Alternative     : Window-Eyes 3.1 full CD (we31.iso, 12.8 MB). It has a
                      talking installer, but asks for a serial and may run as
                      a timed demo.
* Licences: the site has no freeware or licence statements for these readers,
  and no serials. Only "JAWS for DOS 2.31 Freeware" is labelled freeware. Do not
  use: JAWS7.00.135.zip (contains CrackingJAWS7.txt and Jaws KeyGen.exe),
  TTS/OldSoftwareSynths/KEYNOTE CRACK.zip, TTS/SAPI/Infovox/CKKeyGen.exe,
  "Hal 7.01 and reset.exe" (the name suggests a trial reset), and
  JAWS3.31.zip (HJAUTH.EXE/AUTHMAN.EXE, origin unknown).
* Host note: TTS/EloquenceAndViaVoice/SAPI4/eloq50.exe disappeared from disk
  right after download. Antivirus quarantine is likely; it was not inspected.

    Unattended: semi-automatic, documented by the vendor. Disk1/Response.ini
             plus  SETUP.EXE <path>\RESPONSE.INI  skips every dialogue. The
             installer then beeps N times when it wants disk N, and once when
             finished. Untested: whether it finds Disk2..7 on its own when the
             tree is copied to the hard disk.
    Recipe (Polish, software speech):
      1. Unpack osw2demo.exe on the host (it is a zip) to C:\CHARON\OSW\Disk1..7.
      2. Install the SAPI 4 runtime (spchapi.exe /Q:A /R:N) and a SAPI 4
         engine. No free Polish SAPI 4 engine was verified on the site (see
         3.3). With an English engine the prompts are Polish text read in
         English.
      3. Edit Disk1\Response.ini:
           Installation Language=PLK
           Destination=C:\Osw
           Synthesizer=MSSAPI         (or NO_SPEECH, LKT32, KUBSSIL1, BNS1...)
           SpeechPort=COM1            (only for serial synths; BNS1 -> COM1)
           BrailleDisplay=NO_BRAILLE
           StartupMethod=AUTOMATIC    (adds load= to SYSTEM.INI)
           Languages=PLK, ENU
           RestartWindows=YES
      4. Run once: C:\CHARON\OSW\Disk1\SETUP.EXE C:\CHARON\OSW\Disk1\RESPONSE.INI
      5. If it stops at a disk prompt, a sighted step or an emulated floppy
         swap is needed (Charon can mount DiskN as A:).
    Charon note: BNS1 or DTE over the emulated COM1 makes outSPOKEN speak with
             no guest sound driver at all.

    The 3.7+ OS lists are inferred from the bundled Runtime\MSAA\9X files
    (oleacc, user/gdi updates) and release dates. They are not vendor
    statements; the IS6 setup.inx files hold no readable OS list.
    sha256 of every downloaded file is in catalog.json.
    Speech:  Eloquence for JFW bundled (SW; Eloquence languages: US/UK English,
             German, Spanish (2), French, Italian, Portuguese, Finnish). The
             3.31 synth.ini also lists Accent PC/SA, Apollo 2, Artic 215,
             Audapter, Braille 'n Speak, DECtalk Access32/Express/PC,
             DoubleTalk LT/PC, FlexTalk, Infovox, Keynote MM/hardware, Reading
             Edge, "Microsoft Text-to-Speech Engine" (SAPI 4), Multi Voice,
             TextAssist, Sounding Board.
    UI:      English only.
    Demo:    No authorization on the site. Unauthorized JAWS runs a timed demo
             (vendor behaviour, commonly 40 minutes, then restart Windows; not
             verified from these files).
    a) JAWS 3.31 / 3.30 / 3.50: Henter-Joyce script installer. setup.exe
       interprets plain-text install.dat, commproc.inc, custom.inc,
       standard.inc, install.inc, question.inc and makedef.inc from the
       startup directory.
       - If default.ini is present (it ships in jfw33135), setup offers
         "Automatic Install": Eloquence, American English, no braille, no
         merge. That is a "FORCED" install driven entirely by default.ini:
           @JFWDrive = C  @JFWDir = "\\JFW32"  @PrimarySynthShort = "eloq"
           @PrimarySynthDriver = "eloq"  @NumBraille = 0 ...
       - What is still interactive: the "Automatic/Custom" option box
         (commproc.inc, @GetOption ... @Option 500) and @Display/@Pause
         message screens (install.inc and others). These are plain text in
         Charon's own copy of the installer, so they can be removed: set
         @SetOption(104) / @InstallType="FORCED" directly and delete the
         @Pause lines. The Henter-Joyce script language is undocumented
         here, so test the patch once in Bochs.
       - makedef.ini in the startup directory switches setup into
         "Make Defaults" mode. You can use it to produce a different
         default.ini, for example with Braille 'n Speak on COM1 instead of
         Eloquence (synth item "Braille 'n Speak (Win NT or 95/98)").
       - msaardk.exe (MSAA RDK, 1 312 728 B) is inside jfw33135. Run it first on
         Windows 95: msaardk.exe /Q:A /R:N, then reboot.
       - j35037.exe is a PackageForTheWeb SFX. Its MSZIP CAB holds the same
         script installer and can be unpacked on the host with the CAB reader
         used for this survey.
    b) JAWS 3.7 to 6.x: InstallShield 6 (setup.inx, ikernel.ex_, data1.hdr,
       data1.cab). The script contains "InstallShield Silent" handling, so
       setup.exe -s -f1C:\path\setup.iss -f2C:\jaws.log works with a response
       file. No .iss ships, and the dialogue set includes custom steps
       (AskRunJAWSFirst, "Speech Synthesizers"/Eloquence components, serial).
       Writing an .iss by hand is guesswork; a one-time recording
       (setup.exe -r) by a sighted operator in the guest is the reliable way.
       Until then: manual dialogue.

4. Scripted installation in the Charon Windows 9x guest
-------------------------------------------------------------------------------
4.1 Getting control after the first boot. Every method below writes plain
    files on the FAT volume from outside, which Charon can do before booting
    Bochs.
    a) WIN.INI  [windows]  run=C:\CHARON\RINST.BAT   (or load=). Language
       independent: works on Polish Windows, where the StartUp folder is
       "Menu Start\Programy\Autostart". RINST.BAT removes the run= line
       when it is done. Best first choice.
    b) StartUp folder: C:\WINDOWS\Start Menu\Programs\StartUp\RINST.BAT (or the
       localized path). Simple, but the path depends on the language.
    c) AUTOEXEC.BAT (real mode, before Windows):
         C:\WINDOWS\REGEDIT.EXE /L:C:\WINDOWS\SYSTEM.DAT /R:C:\WINDOWS\USER.DAT C:\CHARON\RUNONCE.REG
       RUNONCE.REG:
         REGEDIT4
         [HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\RunOnce]
         "CharonReader"="C:\\CHARON\\RINST.BAT"
       RunOnce entries run once per boot cycle and are removed by Windows, which
       is convenient for the "install, reboot, install next" chains below.
       On Windows ME, AUTOEXEC.BAT is largely ignored and real-mode DOS is
       hidden; use a) or b) there.
    d) Windows 98/ME also accept  REGEDIT /S file.reg  from a batch file
       inside Windows.
4.2 Chain for software speech (95/98), one reboot per step:
       step 1  MSAARDK.EXE /Q:A /R:N                      (Windows 95, 98 FE)
       step 2  SPCHAPI.EXE /Q:A /R:N + MSTTSL.EXE /Q:A /R:N  (only for SAPI readers)
       step 3  the reader:
               JAWS 3.31: patched script installer in C:\CHARON\JFW331 (default.ini,
                          prompts removed) -> SETUP.EXE ; then reboot
               outSPOKEN: SETUP.EXE C:\CHARON\OSW\Disk1\RESPONSE.INI
               JAWS 3.7-6 / WE 3.1 / WE 5.0: SETUP.EXE -s -f1C:\CHARON\x.iss once
                          an .iss has been recorded; otherwise a manual dialogue
               Dolphin / ProTalk / Window-Eyes demos: manual dialogue
       Each step adds the next RunOnce entry before it exits.
4.3 Sound. All SW options need a working sound card driver in the guest
    (SB16 in Bochs; Windows 95 and 98 include a Sound Blaster 16 driver). The
    reader cannot speak during the Windows setup itself.
4.4 HW speech with no guest sound driver: Charon can emulate a serial
    synthesizer on COM1 and speak the text itself (see src/pc/pc_bns.cpp).
    Readers in this catalogue that drive a Braille 'n Speak: JAWS 3.31
    (BNS.RED), Window-Eyes 1.x-3.1 (webns.dll), outSPOKEN 2.01 (BNS1), Hal95
    SAM (Sam/samssil/BNS), ASAW (BNS1.SY_), Windows Master, and the DOS readers
    JAWS DOS, Vocal-Eyes (BNSPEAK.COM) and ASAP. DECtalk Express (DTE) is the
    second most widely supported protocol (JAWS, WE wedtexp.dll, outSPOKEN DTE,
    Hal DTE, ProTalk PTDTXPRS).
4.5 Defaults to offer in the Charon menu:
      Windows 95 / 98 : JAWS 3.31.35 + Eloquence (scripted). Alternatives:
                        Window-Eyes 3.1 (talking manual install), outSPOKEN 2.01
                        demo (Polish UI), Hal95 4.50 (Orpheus).
      Windows ME      : JAWS 4.02.52 (needs an .iss, else manual). Alternatives:
                        JAWS 5.00.844, Window-Eyes 5.0, Hal 5.11.
      Any, no sound   : any BNS-capable reader above, with BNS1 on COM1.
    Licence: none of these Windows readers is marked freeware on the site, and
    their demo or authorization limits apply.
