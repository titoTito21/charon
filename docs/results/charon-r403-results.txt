7. ReactOS installed by Charon - feasibility, and the decision (2026-11-20 night)
   - ReactOS x86 starts only from legacy BIOS (CSM); Charon (UEFI) could reach it only via
     EFI_LEGACY_BIOS_PROTOCOL.LegacyBoot on CSM machines.
   - Install stick made like Rufus (dosmbr.bin + FAT32 with fat32.bin, FREELDR.SYS,
     \loader\rosload.exe - FreeLoader's second stage since 0.4.16 - and the disc tree):
     FreeLoader boots through the BIOS, but Setup's own usbstor fails on EHCI
     (USBSTOR_FdoHandleStartDevice c0000001) and the kernel stops on an assertion.
   - Setup from a RAM disk (SystemPath=ramdisk(0), /RDPATH=reactos.iso /RDEXPORTASCD,
     work/reactos3/make-ros-ramstick.py): loads, copies files, installs boot code
     ("Installing from RamDisk is UNSUPPORTED"); the installed disk then stops at
     "Could not load SYSTEM.ALT hive".
   DECISION (user): ReactOS is dropped - no ReactOS group in Charon. What was learned about
   NVDA in ReactOS stays in point 6.
