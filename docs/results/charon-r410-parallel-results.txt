DESIGN (one API, no second copy of the logic):
 src/efi/CharonDownloads.h (https::many, firmware-free, host-tested): Run(jobs, handler, options, platform). Up to
 Options::connections WORKERS (<= 8); each is one https::Client - own TCP connection, own BearSSL context, HTTP/1.1
 keep-alive - running on its OWN 256 KiB stack (cooperative; switched by the existing tvox_context_swap, no new
 assembly). The client code is unchanged (redirects, chunked, Range resumption, certificate checks); a transport that
 would wait yields to the loop (https::many::Pass) instead of Stall. The loop resumes every worker, verifies completed
 bodies on its own stack while the others go on, reports ONE combined progress, then calls Platform::idle once. Per
 file: optional HEAD probe on the kept connection (CharonHttps.h: a HEAD answer no longer closes a keep-alive
 connection), begin/write/reset/verify/arrived hooks; up to 3 attempts with back-off 1 s, 2 s (network failures,
 5xx/429/408); a failed file never stops the others; Escape stops all; caps: connections, perHost, inFlightBytes; a
 firmware that refuses another TCP child (errNoTcp/errMemory) lowers the count and the batch goes on.
 src/efi/CharonWsDownloads.h (firmware glue, ws::net::many): Download(items, n, options) - targets memory (reserved
 here or the caller's), a file, or the caller's hooks; Platform::idle polls every TCP child, pumps the voice every
 10 ms, Escape every 100 ms, stalls 0.25 ms only when no connection moved; BackgroundPump is on during a batch; names
 said as they arrive with the existing rule (newest + "and N more" / "i jeszcze N"; plan: "Downloaded: X, and 2
 more." / "Pobrano: ..."; "Also downloaded: N." at the end); Explain() says a failure like net::HttpsFail. DNS
 answers are remembered for one batch only (tcp::BatchNames), lookups serialized (the lookup code keeps statics).
 Memory: Worker ~90 KiB + stack 256 KiB + TCP state 66 KiB each, AllocatePool, freed after the batch; Worker aligned
 to 16 inside its block (VM-found: AllocatePool's 8-byte alignment gave #GP on an SSE store, fixed).
