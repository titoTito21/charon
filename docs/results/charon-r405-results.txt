Code changed (NOT compiled yet):
- CharonWsDosSystem.h: the Windows XP profile downloads NVDA 2017.3 into READER\NVDA2017.EXE
  (https://download.nvaccess.org/releases/2017.3/nvda_2017.3.exe, 21 216 304 bytes, SHA-256
  a0ad10a9f33bc5bcde629524e873c3141976f1698915d38640c46f2c140c3972, computed from NV Access's server;
  no official hash is published for that release).
- src/pc/pc_gui.cc (CharonPC): Polish letters given as characters -> Right Alt (AltGr) + letter (Polish
  programmer's layout); Right Alt from a US firmware layout passed on as AltGr; Ctrl+Shift+F11 types
  Ctrl+Alt+Del into the guest.
- CharonWsWinUsb.h: Windows media on a stick that has no \EFI\BOOT\BOOTX64.EFI keeps the ISO's loader
  there (before: always renamed to \efi\microsoft\boot\bootmgfw.efi, so a stick made for another
  computer started nowhere - found when the stick made by Charon was booted in VMware).
- CharonWsInstall2.h (answer file): Narrator after sign-in is written into the DEFAULT user hive in
  specialize (Configuration=narrator, NarratorAfterSigninResetCompleted=1, WinEnterLaunchEnabled=1),
  and NarratorAfterSigninResetCompleted=1 also at first logon.
- CharonWsInstall3.h: Arch from the network uses ip=:::::eth0:dhcp (plain ip=dhcp got no address in QEMU).
- tools/charon-addon/Charon-WindowsProfile.ps1: keeps NarratorAfterSigninResetCompleted=1; ReviOS/AtlasOS
  stop at once when the Windows Security app (Microsoft.SecHealthUI) is missing. Parses under PS 5.1.
