Settings record (REPORT TO COORDINATOR: tools/charon-os reads the same record; not edited here)
----------------------------------------------------------------------------------------------
  V13, magic "CHARS00D", still 48 bytes. byte36 bits 2-4 = formatting groups (bit2 kind, bit3 state and
  warnings, bit4 position; default 7); byte38 bits 2-3 = verbosity profile (0 normal, 1 beginner,
  2 expert). New records: byte40 = 252 (voice and sound-icon outputs off). V12 and older decode as
  before (groups 7, profile 0, their formatting byte kept: who had formatting on keeps it on). A reader of
  the record that accepts only "CHARS00C" rejects V13; one that does not mask byte36 / byte38 with 3 reads
  wrong punctuation / language values. Session 2 changed nothing in the record. A custom profile
  (answer 14) will need V14.
  Resident protocol: charonRelease 410; PackReading bits 30-31 = profile; Resume's progress byte bits 2-4
  = groups. App and driver must be of the same build.
